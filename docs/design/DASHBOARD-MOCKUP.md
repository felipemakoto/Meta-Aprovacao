# Etapa 18 — proposta de dashboard

Mockup criado em 29/09/2026: dashboard-mobile-v1.png. Aguardando aprovação; nenhuma interface implementada.

Objetivo: retomar estudos pelo último resultado salvo. Hierarquia: título Seus estudos, último teste com acertos, ação Revisar meus erros, resultado completo e resumo da atividade. Reutiliza marfim, verde, títulos serifados e corpo sans-serif das telas aprovadas. Simulados permanece Em breve, sem ação disponível. Valores e data são ilustrativos.

Gerado pela ferramenta integrada de imagens, usando resultado-final-390.png como referência de estilo. Prompt integral em dashboard-prompt.txt. Imagem inspecionada: textos legíveis, dez segmentos com sete verdes, pontuação e resumo coerentes. Textura e nuances de rasterização são características do mockup; implementação deve preservar os tokens de fundo sólido existentes.

Após aprovação: implementar /dashboard protegido, consultar dados reais do proprietário, tratar conta sem resultado e falha de carregamento; revisão deve abrir diretamente os erros. Totais de atividade precisam de consulta agregada dos resultados salvos, sem contar a mesma tentativa duas vezes. Não apresentar os números ilustrativos como dados reais. Não antecipar histórico, simulados ou estatísticas detalhadas de etapas posteriores.
